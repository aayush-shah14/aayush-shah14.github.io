Open-vocabulary spatial memory

A persistent 3D map that associates detections and semantic embeddings across frames, accelerated with a custom CUDA kernel.

The idea

An agent acting in a physical space needs more than the latest camera frame. It needs a memory that says what has been observed, where it was, and whether a new detection refers to the same object seen earlier.

Pipeline

  • Run open-vocabulary detection and retain semantic embeddings for each observation.
  • Project detections into a shared 3D coordinate frame.
  • Associate new observations with existing map entities using spatial and semantic similarity.
  • Fuse evidence across time while retaining open-vocabulary labels.

The bottleneck

Association becomes increasingly expensive as both the incoming observation set and the persistent map grow. The operation was structured enough to parallelize, but the naive implementation spent too much time moving and comparing data.

I implemented the temporal 3D association step in CUDA and organized the computation around batched comparisons and reductions. The kernel produced a 2.45× speedup at one thousand observations and remained 2.06× faster at twenty thousand.

Why it matters

The useful output is not only a faster kernel. It is a map that can become context for downstream agents: “the drill was last seen on the left tray” is a more durable representation than a detection tied to one frame.
